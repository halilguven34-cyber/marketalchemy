05 :: PROTOCOL ARCHITECTURE & PURPOSE
Immutable State Machine Protocol
Değişmez Durum Makinesi Protokolü

The Market Alchemy platform operates on a strict V0.8.5 decoupled architecture. The Scanner functions as the sole Producer, writing immutable state artifacts (dashboard.json, assets_full.json, market_signature.json, delta_events.jsonl) to the persistence layer. Clients (Web UI, FastAPI, Telegram Bot, CLI) function as pure Consumers reading these versioned protocol messages without direct coupling to the scanner engine.

Market Alchemy platformu, katı bir V0.8.5 ayrıştırılmış mimari üzerinde çalışır. Tarayıcı (Scanner), kalıcılık katmanına değişmez durum artifact'leri (dashboard.json, assets_full.json, market_signature.json, delta_events.jsonl) yazan tek Üretici (Producer) olarak işlev görür. İstemciler (Web UI, FastAPI, Telegram Bot, CLI) ise tarayıcı motoruyla doğrudan bağlantı kurmadan bu sürümlü protokol mesajlarını okuyan saf Tüketiciler (Consumers) olarak çalışır.

Core Protocol Layers: Çekirdek Protokol Katmanları:
  • Layer 1: MarketAlchemyScanner (Producer)
  • Katman 1: MarketAlchemyScanner (Üretici)
  • Layer 2: Protocol + Immutable Artifacts
  • Katman 2: Protokol + Değişmez Artifact'ler
  • Layer 3: Decoupled Consumers (Web, API, Telegram, CLI)
  • Katman 3: Ayrıştırılmış Tüketiciler (Web, API, Telegram, CLI)
